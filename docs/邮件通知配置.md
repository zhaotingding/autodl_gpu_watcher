# 邮件通知配置

邮件通知使用 SMTP 环境变量。可以在启动环境设置这些变量，或在项目根创建本机 `.env`，由 python-dotenv 读取；实际凭据不提交 Git，不进入安装包。以下示例只含占位值：

```dotenv
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USERNAME=your_account@qq.com
SMTP_PASSWORD=your_smtp_authorization_code
SMTP_FROM=your_account@qq.com
SMTP_TO=your_receiver@example.com
```

SMTP_PASSWORD 填写邮箱服务提供的 SMTP 授权码。应用是否发送邮件仍由 config.yaml 中的通知选项控制。本示例仅是文档，不会设置凭据或开启通知。
