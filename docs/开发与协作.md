# 开发与协作

## 一次安装，使用自己的服务器

当前完整桌面支持 Windows 10/11 和 Python >=3.10，建议官方 Python 3.11。安装 Python 时保留 Tcl/Tk；终端运行 `python -m tkinter` 应出现测试窗口。SSH 监控需要 OpenSSH 客户端，先确认 `ssh -V` 与 `ssh <自己的别名>` 正常。平台登录使用系统 Microsoft Edge；无需另下载 Playwright 浏览器。其他操作系统尚未完整验收，不承诺 Windows 凭据、图标或平台登录功能可用。

```powershell
git clone <从本仓库页面复制的克隆地址>
cd <克隆后的仓库目录>
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m autodl_watcher
```

源码为 editable 安装，修改 `src/` 后重开应用即可运行新代码。也可使用现有兼容脚本 `python tools/gui_entry.py --debug`；调试模式强制关闭电源选项。CLI 使用 `python tools/run_watcher.py --help` 或安装生成的 `autodl-watcher-monitor --help`，不会维护第二套监控业务。

## 个人配置与启动路径

- `config.yaml` 是安全公开示例，默认关闭电源操作，未填写作者的用户名、实例 UUID 或私有 Telemetry 地址。复制为 `config.local.yaml` 填写自己的参数；这个 local 文件不会进入 Git。
- `.ui/` 保存个人服务器、界面偏好、规则、AI 用量及图标；`runtime/` 保存登录会话、运行状态和日志。它们不会进入 Git 或干净构建目录。
- API 密钥仍由 Windows 凭据管理器保存；服务器配置只引用 SSH 别名，不复制私钥。AI 默认关闭，使用自己的服务配置后才可主动发送日志。
- `AUTODL_APP_ROOT` 显式指定资料根，适合测试和独立安装。未指定时，源码用仓库根，EXE 用其所在目录，wheel 用系统用户资料目录。Windows wheel 默认 `%LOCALAPPDATA%/autodl-watcher`。
- `config.local.yaml` 优先于同目录 `config.yaml`；后者不存在时，启动器从包内 `defaults.yaml` 初始化。目录存在或保存成功不等于平台/SSH/AI 已验证。

SSH-only 使用可以不配置 AutoDL 平台。需要平台显存及电源调度时，配置自己的 Telemetry 地址、本人占用标识和实例映射，先以仅监控模式核验；启用电源操作必须是操作者的明确选择。

## 验证与构建

依赖唯一声明为 `pyproject.toml`，不新增另一份手工维护的 requirements 列表，不顺带升级版本。EXE 构建 extra 保留固定 PyInstaller 版本：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe tools/build_exe.py --stage-only
```

离线测试使用合成样本、模拟网络和临时目录，不需要作者的 `.ui/`、SSH、平台账号、API 密钥或已构建 EXE。成品不存在时，相应 Windows EXE 验收跳过；创建成品后还应单独验证它。暂存位于 `.tools/build/release/AutoDLWatcher`，只含程序、依赖和安全示例，不打包个人配置。

构建 wheel 并验证异目录安装：

```powershell
.\.venv\Scripts\python.exe -m pip wheel --no-deps . -w dist
$wheelEnv = Join-Path $env:TEMP "autodl-wheel-env"
py -3.11 -m venv $wheelEnv
& "$wheelEnv/Scripts/python.exe" -m pip install (Get-ChildItem dist/autodl_gpu_watcher-*.whl | Select-Object -Last 1).FullName
$env:AUTODL_APP_ROOT = Join-Path $env:TEMP "autodl-wheel-check"
& "$wheelEnv/Scripts/python.exe" -m autodl_watcher --version
# 可在另一个终端切换到临时目录，用上述解释器启动界面并关闭；不启动监控。
```

验收应分别记录测试、源码窗口、wheel 安装、冻结 worker 和真实服务器。离线测试通过不代表真实平台接口、其他 DPI 或其他操作系统已经验收。CI 只运行离线测试和 wheel 安装检查，不连接任何服务器，也不执行付费 AI 或开关机。

## 提交贡献

先阅读根目录 [AGENTS.md](../AGENTS.md) 的项目约束与技能索引；匹配任务时读取项目技能 [autodl-maintenance](../.agents/skills/autodl-maintenance/SKILL.md)，再按需读取references和 `重构开发规范.md`。新增业务先搜索现有实现；纯计算、采集 IO、调度和 Tk 展示保持单向职责，源代码和 CLI 复用同一业务链路。关键注释解释原因、单位、时间语义和资源所有权，避免逐行翻译代码。

每次修复附上可复现的离线样本或最小回归，说明行为变化、验证范围及未验证内容。使用中文 Git 提交，检查 `git diff --cached` 确认没有个人配置、日志、密钥、私钥或训练资料。不要因为某模块旧而删除有效功能，不在普通回归中启动真实训练、产生 API 费用或执行电源动作。

请使用分支提交，项目不要求贡献者使用作者本机路径、Conda 名称或历史归档。共享接口变更同步调用方、测试和文档；提交 PR 前以一份没有 `.ui/`、`runtime/` 或 `config.local.yaml` 的干净检出完成安装与测试。
