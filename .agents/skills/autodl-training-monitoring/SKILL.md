# 训练发现、进度与SSH采集

适用本仓库v0.9.9对应实现；本轮资料整理核对日期2026-10-15。详细历史证据保留原验证日期与实际/模拟/待验证状态，当前代码与事实优先。个人任务Skill提供通用方法，本技能只补项目特殊约束；历史记录不授予外部操作权限。

## 主要流程

1. 进程未识别、日志混用、进度或显存异常时，读取[任务与日志](references/training-and-ssh.md#任务身份发现与显存)及相应协议章节；只有SSH准入/掉线问题才读[接入故障记录](references/training-and-ssh.md#ssh接入历史故障与回退线索)。
2. 用服务器范围和boot_id/PID/start_ticks区分任务；核对本人/项目范围、实际进程和日志关联，不以tmux存在证明存活，不把宿主PID或整卡显存分配给容器任务。
3. 保持启动器与真实子训练分离、DataLoader去重和各日志族的epoch/step语义。默认解析复用training_events；已确认错误在断连或历史切换后仍保留。
4. 每台至多一项在途采集，复用已认证SSH；失败只由服务按max(间隔,退避)调度，停止仅回收自有连接。后台结果须按代次整份接纳或丢弃，视图只用服务公开查询，不新增切页采样。
5. 根据修改使用test_v084.py、test_training.py、test_training_service.py、test_training_window.py及相关日志协议离线回归。API规则生成另匹配AI规则技能，不要求普通训练查看加载它。

按任务选读，不要求先加载其他项目技能。完整行为契约和既有验收仅在需要时查[重构开发规范](../../../重构开发规范.md)和[验收记录](../../../docs/重构验收记录.md)。
