# 训练专用规则与AI用量

适用本仓库v0.9.9对应实现；本轮资料整理核对日期2026-10-15。详细历史证据保留原验证日期与实际/模拟/待验证状态，当前代码与事实优先。个人任务Skill提供通用方法，本技能只补项目特殊约束；历史记录不授予外部操作权限。

## 主要流程

1. 读取[规则与用量](references/rules-and-usage.md)中匹配问题的部分。先核对任务身份、日志来源、当前卡片规则适用状态和已有缓存，不预设空返回、PID不匹配与格式不适用是同一问题。
2. 保持AI输出为受限字段/模板，不执行返回代码或命令；按原日志记录位置与默认事件解析合并，不能清除错误或参与电源判定。生成后及后续采样都验证实际卡片结果。
3. 更新前保存有效profile，失败、空结果、保存异常及中断仍保留它。自动模式每任务一次；规则应用是本地重新解析，不逐轮收费或额外采SSH。
4. 全局设置供所有服务器使用，密钥留Windows凭据管理器。记录调用时Token/缓存/价格，未知不补零；取消只承诺已知状态落盘，不保证服务商未计费或响应头前已取消。
5. 以test_training_rules.py、test_training_ai.py、test_training_ai_usage.py、test_ai_lifecycle.py相关模拟验证语义、后续采样和收尾；真实AI调用须有单独明确授权。

按任务选读，不要求先加载其他项目技能。完整行为契约和既有验收仅在需要时查[重构开发规范](../../../重构开发规范.md)和[验收记录](../../../docs/重构验收记录.md)。
