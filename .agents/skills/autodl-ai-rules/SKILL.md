# 训练专用规则与AI用量

本技能保留项目规则身份和计费契约；通用API接入方法不能覆盖现有协议、预算与恢复策略。2026-11-16核对Electron调用入口；参考中的历史实际／模拟证据保留原日期。

1. 从日志来源、任务身份、缓存状态和失败阶段定位，按需读[规则与用量](references/rules-and-usage.md)。默认Electron由`desktop_backend.DesktopAI`复用`AIService`，`training.log`负责原日志读取，`ai.generate`负责生成；纯界面改动结合[桌面入口](../autodl-electron-desktop/SKILL.md)，不另造请求器或账本。
2. 生成前核对服务器范围、真实训练PID／启动身份与日志来源。手动全文与自动生成的输入预算不同，按已有配置处理，超限明确拒绝，不用缓存尾片段冒充全文，也不把全局默认预算直接写回本项目。
3. 输出只能是受限字段／模板，不执行代码或命令，不参与电源判定，不清除已确认错误。保存前验证规则与当前卡片匹配，后续采样仍检查适用性；应用规则仅本地重新解析，不额外采SSH或再次收费。
4. 更新前保留旧有效profile；失败、空结果、无效结构、保存异常及中断不能覆盖它。自动模式每任务一次，打开窗口、重绘或读已有结果不能重新请求。
5. 所有服务器共用项目AI设置，密钥留Windows凭据管理器。记录调用时参数、Token／缓存／单价及已知结果，未知不补零，不按新价格重算历史。取消或退出不证明服务商未计费；结果未知不盲目重发或切换更贵档位。
6. 按改动使用`test_training_rules.py`、`test_training_ai.py`、`test_training_ai_usage.py`、`test_ai_lifecycle.py`，Electron交互再核对后台与窗口链路。覆盖旧规则保留、后续重解析和退出落盘；模拟与真实收费调用分别报告。真实AI调用仍须任务明确授权。

业务基线与历史证据按需查[重构开发规范](../../../docs/重构开发规范.md)和[验收记录](../../../docs/重构验收记录.md)。
