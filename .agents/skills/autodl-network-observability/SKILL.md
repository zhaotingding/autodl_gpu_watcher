# 本机网络连接详情

适用1.0.2源码面板；约定核对日期2026-10-31。它展示操作系统快照、应用请求观测与配置目标，不是抓包器或完整请求审计器。历史测试不能代替当前实测。

1. 改动前按需读取[实现边界与验证](references/connections.md)：改采集先看原生 API/进程身份；改 UI 先看单项在途与观察时间；需要重验时看测试入口。
2. `network_system` 只读本机；`network_activity` 观察已有请求并传递脱敏事件；`network_attribution` 定义请求证据；`network_monitor` 负责本实例身份、有界历史和关联；`network_ui` 只通过后台快照展示。不得按程序名把其他应用算进来，不从视图触发业务重拨、真实探测或断开连接。
3. PID 与创建时间共同核对；读取不完整只能说明未知。不得把采样值写成真实握手时间、完整请求数、流量或代理路径。
4. 按修改运行原生表/归属、窗口及主界面集成回归。需要实际显示时使用隔离资料和合成行；实际读表可用本机回环。真实服务器、已有应用和个人数据不是默认验收对象。
5. 修改网址归因先读参考资料的“请求归因证据”。PID和TCP源/目标IP、端口全匹配才可写已匹配；只有对端或进程请求证据必须标候选。没有证据则未核对，不能凭443端口或IP猜HTTPS/网址；198.18/15只能提示TUN/Fake-IP可能，不能证明已走代理。

使用方式见[网络连接详情](../../../docs/使用说明.md#6-网络连接详情)。
