# 主题实现与验证

## Electron外观

2026-11-15按用户确认对齐消息萃取当前中性黑灰，深色主背景`#1b1b1b`、面板`#222222`、标题栏`#242424`，浅色标题栏`#ececec`。`main.cjs`使用hidden标题栏和44像素titleBarOverlay，`desktop.theme`同时更新原生覆盖区颜色；HTML菜单按钮no-drag，空白区drag。

本轮实际Electron验收通过四菜单位置、深浅切换、900×660布局、文件/编辑原生菜单弹出与取消，以及编辑框焦点保留。完整窗口截图实测原生控制区与标题背景深色均RGB(36,36,36)，浅色均RGB(236,236,236)。Windows GPU窗口PrintWindow在本机返回全黑，截图辅助程序因此读取已核对测试PID窗口的实际桌面像素，由颜色断言判断结果。

2026-11-16补充实际截图约束：用户其它窗口可能遮挡测试窗口，辅助程序仅临时置顶已核对PID的测试窗口，保持位置、大小与键盘焦点，取图后恢复原置顶状态。源码入口实测通过，不能用其它窗口的桌面像素判断主题是否正确。

## 旧Tk兼容界面

修改外观设置、Tk原生控件或新弹窗时读取。2026-11-02，1.0.3源码约定；验证状态以本节证据和CHANGELOG为准。

- `ThemeManager`启动读取个人YAML，用户选择时合并磁盘最新内容、成功写入后应用。正常监控保存也读取并合并现有文件，因此能保留`ui.theme`。文件损坏不在启动时自动重写。
- `theme.Label`保留请求的语义前景色，将后续`configure`中的错误/成功/提醒映射到当前主题；默认标签由ttk样式决定。训练Tk卡片使用`card_colors`和`_theme_card`，不能用通用背景覆盖成功/异常含义。
- 当前控件切换由`apply_tree`更新；新Toplevel/Text映射时处理。没有定时全树遍历，也不通过业务采样来刷新外观。
- ScrolledText自带原生滚动条不随clam完整配色，替换一次为ttk滚动条并保留滚动指令；已创建的Combobox下拉列表也须更新，不能只设置以后创建时的option默认值。
- 复用现有勾选图片并保留生命周期，换色不能退回X；平台Treeview标签、Text标签、训练进度条及状态色均需核对。后台线程不操作Tk。
- `test_theme.py`覆盖主题键合并与重读、写入失败、已开/新开窗口、动态错误、下拉框与滚动条、卡片状态和文本对比度；`test_gui_window.py`保留勾选形状与主界面生命周期核对。

本轮专项5项与全量608项回归通过；真实隔离Tk窗口已查看深色设置/网络/训练/原日志及浅色训练页。该证据来自临时资料和合成采样，没有替用户重开正在运行的应用。全量结果记录在CHANGELOG；元数据校验不等于未来客户端已自动发现此技能。
