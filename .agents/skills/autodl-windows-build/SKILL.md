# 独立安装与Windows构建

适用本仓库v0.9.9对应实现；本轮资料整理核对日期2026-10-15。详细历史证据保留原验证日期与实际/模拟/待验证状态，当前代码与事实优先。个人任务Skill提供通用方法，本技能只补项目特殊约束；历史记录不授予外部操作权限。

## 主要流程

1. 安装/构建/入口问题读取[独立安装与成品](references/packaging.md)；仅涉及图标时读取[图标四环节](references/icons.md)。普通构建不因索引存在就做图标专项操作。
2. pyproject.toml是唯一依赖声明，__version__是版本来源，不顺带升级依赖。区分代码根与资料根；从无个人配置的干净副本安装，不依赖维护者的Conda、usersite或绝对路径。
3. 涉及成品构建时先构建暂存目录，再验证源码资源、冻结GUI/worker与安全默认配置；安装或入口问题按改动验证异目录wheel、资料定位及真实窗口，不要求为纯安装诊断构建EXE。涉及worker再验证精简PATH及停止退出，未验平台不宣称兼容。
4. 图标变化分原件、转换、框架加载、系统显示核对；ICO保留作者帧，PNG各尺寸从原图生成。EXE资源更新必须保留PyInstaller归档；首次和热更换及实际入口分别检查。
5. 任务包含本地程序替换时，验证通过后才替换，保留个人资料及可恢复旧程序；制作干净包时不得带入本机配置/会话/规则。使用test_package_layout.py、test_portable_startup.py；只有图标相关才使用test_app_icon.py、test_v090.py和实际显示验证。

按任务选读，不要求先加载其他项目技能。完整行为契约和既有验收仅在需要时查[重构开发规范](../../../重构开发规范.md)和[验收记录](../../../docs/重构验收记录.md)。
