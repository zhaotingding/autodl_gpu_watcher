# Windows安装交付与源码启动

当前安装链自1.1.3提供Windows x64当前用户安装版，原目录修复自1.2.0支持。2026-11-16核对；现行版本读取`src/autodl_watcher/__init__.py`，不把本段起始版本当最新版本。

| 任务 | 条件资料 |
| --- | --- |
| 安装、目录选择／修复、卸载、随包后台、应用更新 | [安装、资料与更新](references/installer.md) |
| 源码环境、wheel、轻量EXE与旧启动方式 | [Conda与轻量启动器](references/packaging.md) |
| 图标原件、转换、EXE资源或Windows实际显示 | [图标四环节](references/icons.md) |
| 只处理用户设置兼容与历史数据恢复 | [配置与资料维护](../autodl-maintenance/SKILL.md) |

1. 源码Python依赖来自`pyproject.toml`，Electron和构建工具来自`desktop/package.json`及锁文件。开发使用专用Conda；源码轻量EXE启动源码，不能当成脱离Conda的安装成品。已有开发环境保持有效，不为文档或普通修复迁移环境。
2. 安装版主EXE调用随包`autodl-backend.exe`，内部bridge／monitor／discover／login／exe-icon复用后台；分别核对主进程、后台和worker的运行时、模块、资源根与资料根。冻结后台调用外部程序的DLL查找处理沿用安装实现。
3. `installer/`跟踪安装／卸载／更新实现，`installer/dist/`放发行产物，本机`installed/`与个人资料按忽略规则保护。程序目录、可写资料和凭据分开；更换目录只处理已核实的安装实例，失败不继续清旧目录。
4. 安装、升级和首次设置复用已有资料。保留主题、账号配置、历史、规则、账本与系统凭据；密钥留空保留，允许跳过。手动完成页与自动更新重启分别走设置／原工作台，不把恢复偏好视为授权电源或AI执行。
5. 图标分别核对原件、转换、框架／PE加载与Windows显示。源码轻量启动器和安装构建写入EXE资源各走自身入口，用户图标用于窗口和快捷方式；不以窗口图标存在推断磁盘EXE正确。
6. 依变更验证源码启动、随包后台、真实NSIS、资料迁移或双版本应用内更新。注册表查询、安装／卸载和缺失登记测试使用同一普通主机上下文；工具与Explorer观察差异见安装参考。构建成功、回环更新、正式签名和公开发布分别报告，不能用历史记录补齐缺口。
7. 用户保留亲自安装／启动时，只做获批检查，不代装、重开或替换在用程序。旧完整成品的归档／删除和真实发布仍按具体授权。

命令见[README](../../../README.md)与[开发与协作](../../../docs/开发与协作.md)，旧验证见[验收记录](../../../docs/重构验收记录.md)。本次文档校准未执行安装或重建EXE。
